# Cybersecurity Home Lab & Project Portfolio

Welcome to the repository for my Cybersecurity Home Lab documentation. 

This repository contains the Markdown files, network diagrams, and assets used to generate my live portfolio website. 

**View the live portfolio here: [HPereira-74](HPereira-74.github.io)**

## Repository Structure

*   `/`: Contains the homepage (`index.md`) and configuration files.
*   `/projects/`: Contains the detailed write-ups for each lab deployment and simulated attack.
*   `/assets/images/`: Contains all screenshots, network diagrams, and visual proof of work.

## About This Project

This project serves as a working documentation of my practical experience with Blue Team Cyber Security, specifically focusing on SIEM deployment, log analysis, and endpoint threat detection.
